五、L4：玩法闭环（好不好玩）

现在能验证"能不能跑、有没有崩"，但这不是游戏质量的判据。闭环设计：

  • pipeline/auto_playtest.py：无头浏览器自动试玩 N 局，采集行为指标 —— 单局时长、死亡时间分布、APM/操作频次、资源曲线、前 60 秒流失点、通关率、卡死/无操作时长。
  • 目标体验曲线：立项时定义（例：前 30 秒上手 / 2 分钟首次成长 / 单局 8–12 分钟 / 通关率 15–25%）。
  • 判定与归因：实测曲线与目标偏差超阈值 → 归因到具体设计参数 → 自动调参或让策划 agent 改设计 → 重生成 → 再试玩。
  • 每次迭代产生一个 EvidencePack，全过程可追溯；设迭代上限，超上限上报人工而不是无限循环。
